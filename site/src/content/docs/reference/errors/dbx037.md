---
title: "DBX037: The pseudonym prefix differs from the period's prefix"
description: "The pseudonym prefix differs from the period's prefix."
---

This page explains error DBX037 and how to fix it.

## Cause

`DeedboxBuilder.PseudonymPrefix` sets a prefix that differs from the prefix the period was created with. A period keeps its prefix, so each person keeps one subject ID in it. The message names the period, the tenant and both prefixes.

## Fix

Set the prefix back to the value the message names. To change the prefix, deploy the change when a new period starts: the new period uses the new prefix, and erasure by identity still uses each period's own prefix.
