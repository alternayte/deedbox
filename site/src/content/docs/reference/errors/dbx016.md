---
title: "DBX016: Stored events have no mapping"
description: "Stored events have no mapping."
---

This page explains error DBX016 and how to fix it.

## Cause

Start-up found stored events whose name maps to no registered event. Usually an event class was renamed.

## Fix

Add `.Alias("old.name")` to the event that replaces it. See [rename an event](/how-to/rename-an-event/).
