---
title: "DBX026: A personal-data property cannot be encrypted"
description: "A personal-data property cannot be encrypted."
---

This page explains error DBX026 and how to fix it.

## Cause

Deedbox encrypts a `[PersonalData]` property as one top-level property of the event's JSON, and reads it as null after erasure. Start-up fails when it cannot do that. The message names the property and one of these causes:

- The property's type cannot hold null.
- The attribute is on a property of a type nested in the event, such as an address in a list. Deedbox encrypts only the event's own properties, so Deedbox cannot protect the nested value, and refuses to store it in plain text.
- The event's JSON contract does not write the property as a property of the event. A custom converter or a contract change hides it.

## Fix

- Make the property a `string` or a nullable type.
- Move a nested personal property to the event, or mark the whole nested property of the event with `[PersonalData]`.
- Serialize the event as a plain object, or remove the attribute.
