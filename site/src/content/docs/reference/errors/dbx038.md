---
title: "DBX038: This instance was not counted as live"
description: "This instance was not counted as live."
---

This page explains error DBX038 and how to fix it.

## Cause

Each app instance writes a heartbeat. An inline projection switches from catch-up to inline only when every live instance that can append its events also runs it. This instance did not write its heartbeat for the liveness window, for example because the process was paused or its connection pool was exhausted. A projection then switched to inline without it. The append does not apply that projection, so Deedbox refuses the append.

Deedbox retries an append in a transaction that it owns, so you see this error only for an append in your own transaction, through `UseTransaction` or `UseDbContext`.

## Fix

Roll the transaction back and run it again. With `UseDbContext`, use a new DbContext: the old one counts its changes as saved. The instance has joined again by then, and the projection is back in catch-up until this instance stops. If the error repeats, find out why the heartbeat fails: log event 40 records each failed heartbeat.
