---
title: "DBX030: Encrypted data or a key does not verify"
description: "Encrypted data or a key does not verify."
---

This page explains error DBX030 and how to fix it.

## Cause

An encrypted field, a subject key or a stored state does not verify. It was altered, or copied from another row.

## Fix

Restore the row from a backup. Deedbox does not read it as erased.
