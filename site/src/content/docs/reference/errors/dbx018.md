---
title: "DBX018: An event version has no upcaster"
description: "An event version has no upcaster."
---

This page explains error DBX018 and how to fix it.

## Cause

An event's version has no upcaster for one of its older versions, or a typed upcaster is not the last step, or a step is past the current version.

## Fix

Add `up.From(n, json => ...)` for every version from 1 to the current one minus 1. See [change an event's shape](/how-to/change-an-event-shape/).
