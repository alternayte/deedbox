---
title: "DBX035: A live instance still registers the projection"
description: "A live instance still registers the projection."
---

This page explains error DBX035 and how to fix it.

## Cause

`deedbox retire` or `IEventStoreAdmin.RetireAsync` names a projection or subscription that a live app instance still registers. Deedbox does not retire it, because that instance still applies it. The message names each instance.

## Fix

Deploy a version of the app without the projection, and wait for the old instances to stop. Then retire it. An instance that stops cleanly leaves at once; one that crashed counts as live for 30 seconds after its last heartbeat.
