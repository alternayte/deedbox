title: "DBX029: The master key cannot unwrap a key"
description: "The master key cannot unwrap a key."
---

This page explains error DBX029 and how to fix it.

## Cause

The configured master key cannot unwrap a tenant key, the key ring is missing or not valid, or a key version is unknown. Deedbox stops rather than read personal data as erased.

## Fix

Configure the master key that wrapped the keys, or add its version to the key ring. See [master key runbook](/operations/master-key/).
