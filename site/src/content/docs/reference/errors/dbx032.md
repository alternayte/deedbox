---
title: "DBX032: A QueueBox publication is not valid"
description: "A QueueBox publication is not valid."
---

This page explains error DBX032 and how to fix it.

## Cause

A QueueBox publication names an unregistered event, publishes an event twice, uses a name that is not a plain identifier, or publishes personal data without a payload mapping.

At append time, a message callback returns an empty topic, a topic over 255 characters, a header with an empty name or a null value, or throws. The append rolls back.

## Fix

Fix the publication. For an event with `[PersonalData]`, pass a payload that holds only what the receiver needs. For a message callback, return a valid message, or return null to skip the event. The exception message and the inner exception name the event.
