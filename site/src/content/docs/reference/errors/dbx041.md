---
title: "DBX041: An instance of the store cannot read archived events"
description: "An instance of the store cannot read archived events."
---

This page explains error DBX041 and how to fix it.

## Cause

You archived streams with `ArchiveStreamsAsync`, `ArchiveStreamAsync` or `deedbox archive`, and a heartbeat row in `deedbox.instances` comes from Deedbox 0.7 or earlier.

Those versions do not read `deedbox.events_archive`. When such an instance rebuilds the stored state of an archived stream, it replays only the events that are still in `deedbox.events`, and stores a wrong state. So Deedbox archives nothing while such a row exists. The row can belong to a stopped instance: Deedbox deletes a row ten liveness windows after its last heartbeat.

## Fix

1. Finish the deploy of 0.8 or later on every app that uses the store.
2. Wait until the old rows are gone from `deedbox.instances`.
3. Archive again.

After the first archive, do not roll back to 0.7 or earlier.
