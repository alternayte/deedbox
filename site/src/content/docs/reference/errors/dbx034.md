---
title: "DBX034: Native json columns are not available or not applied"
description: "Native json columns are not available or not applied."
---

This page explains error DBX034 and how to fix it.

## Cause

`UseSqlServer` has `NativeJson` on, and one of these is true:

- The server has no `json` type. SQL Server 2025, Azure SQL Database and Azure SQL Managed Instance have it.
- A JSON column in the Deedbox schema is still `nvarchar(max)`.

## Fix

On a server without the `json` type, turn `NativeJson` off.

To convert the columns, run `deedbox schema apply --provider sqlserver --native-json`, or call `ApplySchemaOnStartup()`. The conversion rewrites every row of each table.
