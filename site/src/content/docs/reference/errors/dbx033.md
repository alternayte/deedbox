---
title: "DBX033: A projection or subscription name is not registered"
description: "A projection or subscription name is not registered."
---

This page explains error DBX033 and how to fix it.

## Cause

`IEventStoreAdmin.RebuildAsync` or `SkipAsync` names a projection or subscription that the app does not register. Only projections can be rebuilt.

## Fix

Use the name from `Projection<T>(name, run)` or `Subscription<T>(name)`. Run `deedbox status` to list the stored names.
