# Code of conduct

Deedbox follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the repository, its issues and discussions, and every other project space.

Report unacceptable behaviour privately to the maintainer, [@alternayte](https://github.com/alternayte), through [a private report](https://github.com/alternayte/deedbox/security/advisories/new). Start the title with "Conduct". The maintainer reviews every report and keeps the reporter's identity private.
